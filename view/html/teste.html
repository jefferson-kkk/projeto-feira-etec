O PROJETO

Tecnologia que protege o que importa.

O AERIS utiliza sensores, conectividade IoT e automação integrada para oferecer um sistema compacto, eficiente e confiável para monitoramento de gases combustíveis e tóxicos em ambientes residenciais.

COMPONENTES PRINCIPAIS

ESP32

Microcontrolador dual-core com Wi-Fi e Bluetooth. Faz a leitura dos sensores, processa os níveis de gás e envia os dados ao sistema IoT.

DISPLAY OLED

Módulo OLED I2C de baixo consumo. Exibe concentração, estado do monitoramento e alertas sem depender de um computador.

TGS2610

Sensor semicondutor específico para gases combustíveis. Sua resistência varia conforme a concentração detectada, permitindo a medição pelo ESP32.

BUZZER

Transdutor sonoro acionado por sinal elétrico. Emite o alerta audível quando o sistema identifica uma concentração perigosa.

3 LEDs

Indicadores visuais de diagnóstico: verde para operação normal, amarelo para atenção e vermelho para situação de perigo.
